# MacroSlots

Sag Shift ile acilan **9 slotlu replay botu**.

## Ne yapar?

- **Sag Shift** -> menu acar / kapatir
- Menude **1-9** numaralarinin altinda **+** butonlari vardir
- **+** butonuna basinca makro klasorundeki `.gdr2` dosyalari listelenir, birini secince o slota atanir
- **Apply** -> atamalari kaydeder (kapaninca kaybolmaz)
- **1-9** tuslari -> o slottaki makroyu hemen oynatmaya baslar (ekranda yazi cikmaz)
- **0** -> tum makrolari kapatir, oyun normal (legit) moda doner

## Makro dosyalari nereye konur?

Geode menu -> MacroSlots -> **Klasoru Ac** butonuyla acabilirsiniz, ya da manuel olarak:

```
%localappdata%\GeometryDash\geode\mods\kanka.macroslo\macros\
```

Icerine `.gdr2` (veya `.gdr`) makro dosyalarini koyun.
